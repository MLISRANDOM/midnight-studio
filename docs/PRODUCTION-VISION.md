# Midnight Studio production roadmap

Mobile-first AI animation production for TikTok/YouTube Shorts (9:16) and YouTube (16:9).

## Design
Futuristic, responsive console UI with neon cyan and violet highlights, optimized for iPhone.

## Capabilities
- Gemini image generation through a secure backend. Never store the Gemini API key in public client source.
- Character Lock with user-approved reference artwork of Evan and consistent descriptions.
- Story Bible: episodes, locations, rules, character knowledge, and unresolved continuity threads.
- Reference Lab: evaluate user-supplied or accessible linked reference videos and suggest original creative concepts without copying.
- Scene management with frame exports, timing, shot notes, and platform-specific compositions.

## Build order
1. Mobile-first creator console UI.
2. Character and story continuity data model.
3. Secure Gemini image generation gateway.
4. Reference video analysis and original concept generation.
5. Exportable video production packages.
